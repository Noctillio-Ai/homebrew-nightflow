# Homebrew tap for NightFlow

Homebrew cask for [NightFlow](https://github.com/Noctillio-Ai/NightFlow), a desktop app for
managing and analyzing deep learning experiments. Requires macOS Ventura or later on Apple silicon.

```bash
brew tap noctillio-ai/nightflow
brew trust noctillio-ai/nightflow   # Homebrew 7 and later
brew install --cask nightflow
```

The cask is updated automatically by the NightFlow repo's release workflow; please open
issues and pull requests there.
